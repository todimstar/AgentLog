# 文件 2：`ContentService.publish()`（TX-02，本课最硬核）

## 【我在写什么】
发布的事务编排。对应设计文档 `transaction-boundaries.md` 的 **TX-02**（本课简化版，去掉 AI 协作相关步骤）：
```
原文 TX-02（完整版，含 AI 协作）：
1. 锁 Draft；2. 校验 expectedDraftVersion；3. 校验无 ACTIVE Attempt；
4. 汇总 AI 来源；5. 算 content_origin；6. 复制 DraftBlock→PostVersionBlock；
7. 建 PostVersion；8. 写批准人；9. 改治理/可见性；10. Draft→PUBLISHED；
11. 吊销尾 HandoffToken；12. 发事件。

本课 L06 普通发帖只做这几步（其余是 L15+/L20）：
2. 校验 expectedDraftVersion（乐观锁）
6. 复制 DraftBlock → PostVersionBlock
7. 建 PostVersion（version_no 累加）
8. 写批准人 + 时间
9. 按 Demo 策略：NOT_REQUIRED → PUBLISHED
10. Draft → PUBLISHED
   + 把 post 的指针指向新版本、可见性改 PUBLISHED、回填卡片缓存
```
> 第 3/4/11/12 步（ACTIVE Attempt 校验、AI 来源汇总、吊销 HandoffToken、发领域事件）
> 都是 AI 协作相关，本课普通发帖没有 AI，**跳过**。这是"本课不做什么"的明确边界。

## 【为什么】——这一步兑现了整课的灵魂
还记得建模那张图吗？发布的本质是：
```
draft_block（可变）─── 复制快照 ──→ post_version_block（不可变）
                                          ↑
post.current_published_version_id ────────┘ 指针指向它
读者读详情 → 读这个快照，不读 draft → 所以改草稿线上不变
```
**为什么是"复制"而不是"引用"**：如果 post_version 直接引用 draft_block，那主人改草稿，线上就跟着变了——就违反"发布版本不可覆盖"。复制一份冻起来，才能让"线上稳定 + 草稿继续可改"两者并存。这就是**写时复制 / 版本化发布**。

## 【前后关系】
- 前：Controller 传 `currentUserId` + `draftId` + `PublishDraftRequest`（含 expectedDraftVersion）。
- 用到的 Mapper：draftMapper、draftBlockMapper、postMapper、postVersionMapper、postVersionBlockMapper。
  → **Service 构造器要新增注入 postVersionMapper、postVersionBlockMapper 两个**（你之前只注入了 5 个）。
- 后：返回 PublishDraftResponse。

## 【怎么做】——分步拆解

**Step 1 查草稿 + 行级授权**（同接口②）：
```java
DraftDO draft = draftMapper.selectById(draftId);
if (draft == null) throw 404 DRAFT_NOT_FOUND;
if (!draft.getOwnerUserId().equals(currentUserId)) throw 403 DRAFT_FORBIDDEN;
```

**Step 2 校验 expectedDraftVersion（乐观锁，新知识点）**：
```java
if (!draft.getVersion().equals(request.expectedDraftVersion())) {
    throw new ApiException(HttpStatus.CONFLICT, "DRAFT_VERSION_CONFLICT", "草稿已被修改，请刷新");
}
```
> **为什么**：防并发。主人在两个标签页打开同一草稿，A 页发布后 draft.version 变了，B 页拿旧 version 再发布就会冲突——挡掉，避免基于过期内容误发布。这是**乐观锁**思想（你预习硬骨头地图见过，L16/L19 还会深挖）。

**Step 3 校验状态**（只有 EDITABLE/READY_FOR_OWNER_REVIEW 能发；已 PUBLISHED 的不能重复发）：
```java
if (DraftStatus.PUBLISHED.getCode().equals(draft.getStatus())) {
    throw new ApiException(HttpStatus.CONFLICT, "DRAFT_ALREADY_PUBLISHED", "草稿已发布");
}
```

**Step 4 算新版本号 version_no（查当前最大值 + 1）**：
```java
Long maxVersionNo = postVersionMapper.selectCount(
        Wrappers.<PostVersionDO>lambdaQuery().eq(PostVersionDO::getPostId, draft.getPostId()));
int nextVersionNo = maxVersionNo.intValue() + 1;   // 首次发布 = 1，再发 = 2…
```
> 用"已有版本数 +1"算下一个版本号。首次发布 count=0 → v1，再发 count=1 → v2，累加不覆盖。

**Step 5 建 post_version（发布快照头）**：
```java
PostVersionDO version = new PostVersionDO();
version.setPostId(draft.getPostId());
version.setVersionNo(nextVersionNo);
version.setTitleSnapshot(draft.getTitle());          // 快照当时的标题
version.setSummarySnapshot(draft.getSummary());
version.setChannelIdSnapshot(draft.getChannelId());
version.setChannelNameSnapshot(channelName);          // 需查 channel 取名（见参考）
version.setContentOrigin(ContentOrigin.HUMAN_ONLY.getCode());  // 普通发帖=纯人类（无AI）
version.setModerationStatus(ModerationStatus.NOT_REQUIRED.getCode());  // Demo 策略
version.setOwnerApprovedByUserId(currentUserId);     // 谁批准
version.setOwnerApprovedAt(now);
version.setPublishedAt(now);
version.setCreatedAt(now);
postVersionMapper.insert(version);
```
> 注意：这里要用到两个**新枚举** `ContentOrigin`、`ModerationStatus`，你照 DraftStatus 的常量字典风格建一下（见本节末尾「要你补的枚举」）。

**Step 6 复制 draft_block → post_version_block（核心：快照不可变）**：
```java
List<DraftBlockDO> blocks = draftBlockMapper.selectList(
        Wrappers.<DraftBlockDO>lambdaQuery()
                .eq(DraftBlockDO::getDraftId, draftId)
                .eq(DraftBlockDO::getIsHidden, false)        // 隐藏块不发布
                .orderByAsc(DraftBlockDO::getDisplayOrder));
for (DraftBlockDO b : blocks) {
    PostVersionBlockDO vb = new PostVersionBlockDO();
    vb.setPostVersionId(version.getId());
    vb.setSourceDraftBlockId(b.getId());                 // 记来源（可追溯）
    vb.setContributionId(b.getContributionId());
    vb.setAuthorType(b.getAuthorType());
    vb.setAuthorUserId(b.getAuthorUserId());
    vb.setDisplayOrder(b.getDisplayOrder());
    vb.setContentSnapshot(b.getRenderedContent());       // 把可变正文【复制】成不可变快照
    vb.setCreatedAt(now);
    postVersionBlockMapper.insert(vb);
}
```

**Step 7 改 post 指针 + 可见性 + 回填卡片缓存**：
```java
PostDO post = postMapper.selectById(draft.getPostId());
post.setCurrentPublishedVersionId(version.getId());    // 指针指向新版本（读者据此读快照）
post.setVisibilityStatus(PostVisibility.PUBLISHED.getCode());
post.setTitleCache(draft.getTitle());                  // Feed 卡片用，回填
post.setSummaryCache(draft.getSummary());
post.setContentOriginCache(ContentOrigin.HUMAN_ONLY.getCode());
post.setPublishedAt(now);
post.setUpdatedAt(now);
postMapper.updateById(post);   // updateById 会带乐观锁 WHERE version=?（PostDO 标了 @Version）
```

**Step 8 draft 状态 → PUBLISHED**：
```java
draft.setStatus(DraftStatus.PUBLISHED.getCode());
draft.setUpdatedAt(now);
draftMapper.updateById(draft);
```

**Step 9 返回**：
```java
return new PublishDraftResponse(post.getId(), version.getId(), nextVersionNo,
        version.getModerationStatus(), post.getVisibilityStatus());
```

<summary>📦 publish 完整参考实现（先自己写，卡住再看）</summary>

```java
/** TX-02 主人发布：快照复制 + 版本累加 + 指针切换。发布版本不可覆盖。 */
@Transactional
public PublishDraftResponse publish(long currentUserId, long draftId, PublishDraftRequest request) {
    Instant now = Instant.now(clock);

    // 1. 查草稿 + 行级授权
    DraftDO draft = draftMapper.selectById(draftId);
    if (draft == null) {
        throw new ApiException(HttpStatus.NOT_FOUND, "DRAFT_NOT_FOUND", "草稿不存在");
    }
    if (!draft.getOwnerUserId().equals(currentUserId)) {
        throw new ApiException(HttpStatus.FORBIDDEN, "DRAFT_FORBIDDEN", "无权操作他人草稿");
    }

    // 2. 乐观锁校验
    if (!draft.getVersion().equals(request.expectedDraftVersion())) {
        throw new ApiException(HttpStatus.CONFLICT, "DRAFT_VERSION_CONFLICT", "草稿已被修改，请刷新");
    }

    // 3. 状态校验
    if (DraftStatus.PUBLISHED.getCode().equals(draft.getStatus())) {
        throw new ApiException(HttpStatus.CONFLICT, "DRAFT_ALREADY_PUBLISHED", "草稿已发布");
    }

    // 4. 算版本号
    Long existingVersions = postVersionMapper.selectCount(
            Wrappers.<PostVersionDO>lambdaQuery().eq(PostVersionDO::getPostId, draft.getPostId()));
    int nextVersionNo = existingVersions.intValue() + 1;

    // 取分区名做快照
    ForumChannelDO channel = forumChannelMapper.selectById(draft.getChannelId());
    String channelName = channel != null ? channel.getName() : "";

    // 5. 建 post_version
    PostVersionDO version = new PostVersionDO();
    version.setPostId(draft.getPostId());
    version.setVersionNo(nextVersionNo);
    version.setTitleSnapshot(draft.getTitle());
    version.setSummarySnapshot(draft.getSummary());
    version.setChannelIdSnapshot(draft.getChannelId());
    version.setChannelNameSnapshot(channelName);
    version.setContentOrigin(ContentOrigin.HUMAN_ONLY.getCode());
    version.setModerationStatus(ModerationStatus.NOT_REQUIRED.getCode());
    version.setOwnerApprovedByUserId(currentUserId);
    version.setOwnerApprovedAt(now);
    version.setPublishedAt(now);
    version.setCreatedAt(now);
    postVersionMapper.insert(version);

    // 6. 复制 draft_block → post_version_block（快照不可变）
    List<DraftBlockDO> blocks = draftBlockMapper.selectList(
            Wrappers.<DraftBlockDO>lambdaQuery()
                    .eq(DraftBlockDO::getDraftId, draftId)
                    .eq(DraftBlockDO::getIsHidden, false)
                    .orderByAsc(DraftBlockDO::getDisplayOrder));
    for (DraftBlockDO b : blocks) {
        PostVersionBlockDO vb = new PostVersionBlockDO();
        vb.setPostVersionId(version.getId());
        vb.setSourceDraftBlockId(b.getId());
        vb.setContributionId(b.getContributionId());
        vb.setAuthorType(b.getAuthorType());
        vb.setAuthorUserId(b.getAuthorUserId());
        vb.setDisplayOrder(b.getDisplayOrder());
        vb.setContentSnapshot(b.getRenderedContent());
        vb.setCreatedAt(now);
        postVersionBlockMapper.insert(vb);
    }

    // 7. 改 post 指针 + 可见性 + 卡片缓存
    PostDO post = postMapper.selectById(draft.getPostId());
    post.setCurrentPublishedVersionId(version.getId());
    post.setVisibilityStatus(PostVisibility.PUBLISHED.getCode());
    post.setTitleCache(draft.getTitle());
    post.setSummaryCache(draft.getSummary());
    post.setContentOriginCache(ContentOrigin.HUMAN_ONLY.getCode());
    post.setPublishedAt(now);
    post.setUpdatedAt(now);
    postMapper.updateById(post);

    // 8. draft → PUBLISHED
    draft.setStatus(DraftStatus.PUBLISHED.getCode());
    draft.setUpdatedAt(now);
    draftMapper.updateById(draft);

    // 9. 返回
    return new PublishDraftResponse(post.getId(), version.getId(), nextVersionNo,
            version.getModerationStatus(), post.getVisibilityStatus());
}
```

`content/domain/ModerationStatus.java`：值 `NOT_REQUIRED` / `PENDING` / `APPROVED` / `REJECTED` / `HIDDEN`

## ✅ 验证（这是"发布不可覆盖"验收的关键实验）

1. Postman 加一个「5. 发布」请求：`POST /owner/drafts/{{draftId}}/publish`，body：
   ```json
   { "expectedDraftVersion": 0, "publishMode": "AUTO_IF_ALLOWED" }
   ```
   预期 200，返回 postId/postVersionId/versionNo=1/visibilityStatus=PUBLISHED。

2. **查库验快照已复制**：
   ```sql
   SELECT * FROM post_version;        -- 应有 1 行 version_no=1
   SELECT * FROM post_version_block;  -- 应有 1 行 content_snapshot=你的正文
   SELECT current_published_version_id, visibility_status FROM post;  -- 指针指向 version，PUBLISHED
   ```

3. **验"不可覆盖"**（核心实验，接口④实现后做）：发布后改 draft_block 的内容 → 再查 post_version_block →
   **它纹丝不动**。这就证明了快照独立于草稿。
