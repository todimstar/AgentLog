# 接口① 手工验收脚本（建草稿）· PowerShell 原生版

> 用 PowerShell 原生 `Invoke-RestMethod`，不用 curl.exe。
> 原因：PowerShell + curl.exe 传中文会被按系统 GBK 编码发出，后端按 UTF-8 解析 → 400 "Failed to read request"。
> `Invoke-RestMethod` + 显式 UTF-8 字节体可正确发中文，且自动管理 Session Cookie。

## 验收脚本（在第二个 PowerShell 窗口，整段粘贴执行）

```powershell
$ErrorActionPreference = "Stop"
$BASE = "http://localhost:8080/api/v1"

# 小工具：把对象转成 UTF-8 字节体（关键：避免 PowerShell 默认 GBK 编码）
function To-Utf8Json($obj) {
    $json = $obj | ConvertTo-Json -Compress
    return [System.Text.Encoding]::UTF8.GetBytes($json)
}

# 1. 拿 CSRF + 建立会话（GET /csrf 是 permitAll，必 200；-SessionVariable 建会话罐子）
$csrf  = Invoke-RestMethod -Uri "$BASE/web/csrf" -Method Get -SessionVariable session
$token = $csrf.token
Write-Host "CSRF token = $token"

# 2. 注册（register 豁免 CSRF，带不带都行；用 UTF-8 字节体，中文 OK）
try {
    $u = Invoke-RestMethod -Uri "$BASE/web/auth/register" -Method Post `
            -ContentType "application/json; charset=utf-8" `
            -Body (To-Utf8Json @{ username="l06tester"; password="password123"; displayName="L06测试员" }) `
            -WebSession $session
    Write-Host "注册成功: $($u.username) / $($u.displayName)"
} catch {
    Write-Host "注册返回（可能已存在，忽略）: $($_.Exception.Message)"
}

# 3. 登录（带 CSRF 头；成功后 JSESSIONID 进会话罐子）
$me = Invoke-RestMethod -Uri "$BASE/web/auth/login" -Method Post `
        -ContentType "application/json; charset=utf-8" `
        -Headers @{ "X-XSRF-TOKEN" = $token } `
        -Body (To-Utf8Json @{ username="l06tester"; password="password123" }) `
        -WebSession $session
Write-Host "登录成功: $($me.username)"

# 4. 刷新 CSRF（登录后 Spring 会轮换 token，重新取一次最稳）
$token2 = (Invoke-RestMethod -Uri "$BASE/web/csrf" -Method Get -WebSession $session).token

# 5. 【核心】建草稿 —— 调接口① （channelId 改成步骤0里的真实 id）
$draft = Invoke-RestMethod -Uri "$BASE/owner/drafts" -Method Post `
            -ContentType "application/json; charset=utf-8" `
            -Headers @{ "X-XSRF-TOKEN" = $token2 } `
            -Body (To-Utf8Json @{
                title                     = "修了个CSRF死锁"
                channelId                 = 1
                content                   = "今天踩了个坑：permitAll 不免 CSRF……"
                summary                   = "一次 CSRF 死锁的复盘"
                declaredExternalAiContent = $false
            }) `
            -WebSession $session
$draft | ConvertTo-Json -Depth 5
```

**预期**：最后打印
```json
{
  "draftId": 1,
  "title": "修了个CSRF死锁",
  "status": "EDITABLE",
  "version": 0,
  "blocks": [
    { "blockId": 1, "displayOrder": 0, "content": "今天踩了个坑：permitAll 不免 CSRF……", "sourceTool": null }
  ]
}
```
能看到中文不乱码 = 后端 UTF-8 链路通。

## 踩坑预案
- **400 Failed to read request**：请求体编码坏了。确认用的是本脚本的 `To-Utf8Json`（字节体），不是 curl.exe 直接传中文。
- **403 调建草稿**：CSRF 头没带或过期 → 重跑第 4 步刷新 $token2 再跑第 5 步。
- **401**：没登录态 → 确认第 1、3 步用了同一个 `$session`。
- **CHANNEL_NOT_FOUND**：channelId 不存在 → 回步骤 0 确认真实 id。
- **500 提到 created_at/version**：DO 某 NOT NULL 字段没设值 → 回 Service 检查。
