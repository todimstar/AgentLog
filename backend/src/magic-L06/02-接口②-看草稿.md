# 文件 1：`ContentService.getDraft()`（核心）

## 【我在写什么】
"按 id 查一篇草稿详情"的业务方法。对应 OpenAPI `GET /owner/drafts/{draftId}` → 返回 `DraftView`。

## 【为什么】
- 接口① 建完草稿返回了 DraftView，但用户**刷新页面/重新进入编辑器**时，前端要重新拉一次草稿——就是调它。
- 它要把"草稿头（draft 表）+ 它的所有正文块（draft_block 表）"拼成一个完整 DraftView。

## 【前后关系】
- 前：Controller 传进 `currentUserId`（登录态）+ `draftId`（URL 路径参数）。
- 复用：接口① 已写的 `DraftView.from(draftDO, blockDOs)`——同一个翻译方法，这里再用一次。
- 后：返回 DraftView 给 Controller。

## 【怎么做】——三步

**Step 1 查草稿头**：
```java
DraftDO draft = draftMapper.selectById(draftId);
if (draft == null) throw new ApiException(NOT_FOUND, "DRAFT_NOT_FOUND", "草稿不存在");
```

**Step 2 行级授权（⚠️ 安全关键，本课第一次出现）**：
```java
if (!draft.getOwnerUserId().equals(currentUserId)) {
    throw new ApiException(HttpStatus.FORBIDDEN, "DRAFT_FORBIDDEN", "无权访问他人草稿");
}
```
> **为什么必须有这一步**：设计文档 P0 铁律——`owner/*` 所有资源都要做**行级归属校验**。
> 没有它，登录用户 A 改一下 URL 里的 draftId，就能看用户 B 的私密草稿（这叫 **IDOR 越权漏洞**，
> OWASP 常见高危）。memory 里记着这是本项目"五问复查"P0 级风险点。**这就是你旧论坛常忽略、
> 但生产必做的安全实践**——也是能讲进面试的点。

**Step 3 查该草稿的所有块（MyBatis-Plus 条件查询，新知识点）**：
```java
List<DraftBlockDO> blocks = draftBlockMapper.selectList(
        Wrappers.<DraftBlockDO>lambdaQuery()
                .eq(DraftBlockDO::getDraftId, draftId)        // WHERE draft_id = ?
                .orderByAsc(DraftBlockDO::getDisplayOrder));   // ORDER BY display_order ASC
return DraftView.from(draft, blocks);
```

### 新知识点：`LambdaQueryWrapper`（你 L05 见过 `Wrappers.lambdaQuery`）
- `Wrappers.<T>lambdaQuery()` 造一个"条件构造器"，链式拼 WHERE/ORDER BY。
- `.eq(DraftBlockDO::getDraftId, draftId)` = `WHERE draft_id = ?`，用方法引用（`DO::getXxx`）指定列，**编译期类型安全**（写错字段名编译就报错，不像裸 SQL 字符串）。
- `.orderByAsc(...)` = `ORDER BY ... ASC`。
- `selectList(...)` 返回多行。
- 你在 `IdentityService` 注册查重 `selectCount(Wrappers...eq(UserAccount::getUsername, ...))` 用过同款——这次是 selectList + 排序。

<details>
<summary>📦 getDraft 参考实现（加在 ContentService 里）</summary>

```java
// 顶部 import 补充：
// import com.baomidou.mybatisplus.core.toolkit.Wrappers;

/** 查自己的草稿详情：查头 → 校验归属 → 查块（排序）→ 拼 DraftView。只读，无需 @Transactional。 */
public DraftView getDraft(long currentUserId, long draftId) {
    // 1. 查草稿头
    DraftDO draft = draftMapper.selectById(draftId);
    if (draft == null) {
        throw new ApiException(HttpStatus.NOT_FOUND, "DRAFT_NOT_FOUND", "草稿不存在");
    }

    // 2. 行级授权：只能看自己的草稿（P0 防 IDOR 越权）
    if (!draft.getOwnerUserId().equals(currentUserId)) {
        throw new ApiException(HttpStatus.FORBIDDEN, "DRAFT_FORBIDDEN", "无权访问他人草稿");
    }

    // 3. 查该草稿所有块，按 display_order 升序
    List<DraftBlockDO> blocks = draftBlockMapper.selectList(
            Wrappers.<DraftBlockDO>lambdaQuery()
                    .eq(DraftBlockDO::getDraftId, draftId)
                    .orderByAsc(DraftBlockDO::getDisplayOrder));

    return DraftView.from(draft, blocks);
}
```
</details>

# 文件 2：`OwnerDraftController.getDraft()`（加一个端点）

## 【我在写什么】
`GET /owner/drafts/{draftId}` 的 HTTP 入口。在你已写好的 `OwnerDraftController` 里**加一个方法**。

## 【怎么做】
- `@GetMapping("/drafts/{draftId}")`
- 用 `@PathVariable long draftId` 接 URL 路径里的 id（你旧论坛常用，老朋友）。
- 同样 `CurrentUser.requireId()` 拿登录身份，传给 Service。

<details>
<summary>📦 参考实现（加在 OwnerDraftController 里）</summary>

```java
// import org.springframework.web.bind.annotation.GetMapping;
// import org.springframework.web.bind.annotation.PathVariable;

@GetMapping("/drafts/{draftId}")
public DraftView getDraft(@PathVariable long draftId) {
    long currentUserId = CurrentUser.requireId();
    return contentService.getDraft(currentUserId, draftId);
}
```
</details>
